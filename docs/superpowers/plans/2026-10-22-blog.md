# Blog (F-013) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Public blog at `/blog` + admin section at `/dashboard/blog` + agent-facing token-authenticated API + media on DigitalOcean Spaces.

**Architecture:** Three new tables (`blog_posts`, `blog_post_events`, `api_tokens`); a second auth guard `requireBlogAuth` used ONLY under `app/api/blog/**`; a profile-parameterised sanitiser; a rich-text editor extracted from Notes; public pages rendered dynamically with a single `unstable_cache`-tagged query invalidated by `revalidateTag('blog')`.

**Tech Stack:** Next.js 16 (App Router, classic caching model — `cacheComponents` is NOT enabled and must stay off), Tailwind v4, Drizzle ORM + postgres.js, Vitest, `@aws-sdk/client-s3` + `image-size` (new deps, task 13).

**Spec:** `docs/superpowers/specs/2026-10-22-blog-design.md` — read it before starting any task. Where this plan and the spec disagree on *mechanism* (caching), this plan wins; the deviation is recorded in Global Constraints.

## Global Constraints

- **Auth guard first.** The first statement of every new route handler is `requireBlogAuth(request)` (blog routes) or `requireAdminAuth(request)` (token routes). No exceptions.
- **Never log a token value or a raw query error.** Token logging: prefix (first 12 chars) only. Query errors: `logQueryError` from `lib/dashboard/api.ts`, never `console.error(label, error)`.
- **Wire format** (binding conventions, `docs/ARCHITECTURE.md`): errors `{ error: CODE, message }` via `apiError()`; create → bare entity 201; update → bare entity 200; delete → `{ ok: true }`; list → one named collection key.
- **Route params** are `{ params: Promise<{ id: string }> }` → `const { id } = await params`. Guard with `isUuid` → 404.
- **Caching mechanism (deviation from spec, decided at plan time):** `DATABASE_URL` is `RUN_TIME`-scoped on App Platform (docs/ARCHITECTURE.md → Env vars), so build-time prerendering of DB-backed pages would fail or hang the deploy. Public blog pages therefore export `const dynamic = "force-dynamic"` and read data through ONE `unstable_cache(..., { tags: ["blog"], revalidate: 300 })` query; every mutation calls `revalidateTag("blog")`. Spec semantics preserved: scheduled posts appear ≤5 min, mutations invalidate instantly, nothing queries the DB at build. Do NOT use `export const revalidate` on pages and do NOT enable `cacheComponents`.
- **Timestamps are strings.** All `timestamptz` columns use `mode: "string"` and come back as ISO strings via the parser re-assertion in `lib/db/client.ts`. `if_updated_at` comparison is **exact string equality** with the stored `updated_at`.
- **`NEXT_PUBLIC_*` env vars must be read statically** (literal property access). New server-only env vars go through helpers in `lib/env.ts`.
- **Verification gate for every task:** `npm run lint && npx tsc --noEmit && npm test && npm run build` — run each command separately and check ITS exit code (`echo $?`); never pipe-and-echo.
- **Notes must stay behaviourally unchanged** through tasks 6 and 10 — `lib/sanitize.test.ts` and manual smoke of `/dashboard/notes` are hard gates.
- **Dispatch model tiers** (repo workflow): tasks in this plan contain complete code → cheapest tier for transcription-shaped tasks (1, 2, 4, 7, 14); mid-tier for integration-heavy tasks (3, 5, 6, 8, 9, 10, 11, 12, 13) and all reviewers; most capable model for the final whole-branch review.
- Work on branch `feat/blog` (already exists). Commit per task.

```ts
import crypto from "crypto";

/**
 * Blog API tokens (F-013). Format: "pbk_" + 32 random bytes base64url.
 *
 * Stored as SHA-256 hex, looked up by hash. SHA-256 (not argon2) is correct
 * here: the token carries 256 bits of entropy, so a slow hash adds nothing,
 * and lookup must be by deterministic hash. The full value is shown once at
 * creation and never again; everywhere else only the prefix may appear.
 */

const TOKEN_PREFIX = "pbk_";
/** "pbk_" + 8 — safe to display and to log. */
export const TOKEN_DISPLAY_PREFIX_LENGTH = 12;

/** 32 bytes → 43 base64url chars, no padding. */
const TOKEN_PATTERN = /^pbk_[A-Za-z0-9_-]{43}$/;

export function mintApiToken(): { token: string; hash: string; prefix: string } {
  const token = TOKEN_PREFIX + crypto.randomBytes(32).toString("base64url");

  return {
    token,
    hash: hashApiToken(token),
    prefix: token.slice(0, TOKEN_DISPLAY_PREFIX_LENGTH),
  };
}

export function hashApiToken(token: string): string {
  return crypto.createHash("sha256").update(token, "utf8").digest("hex");
}

/**
 * Cheap shape check run before any DB lookup, so garbage never costs a query
 * and a malformed header can be rejected as 401 without touching Postgres.
 */
export function isWellFormedToken(value: string): boolean {
  return TOKEN_PATTERN.test(value);
}
```

```ts
import { and, eq, isNull, sql } from "drizzle-orm";
import { NextRequest, NextResponse } from "next/server";

import { isAdminEmail } from "@/lib/auth/admin";
import { verifyClaims } from "@/lib/auth/claims";
import {
  TOKEN_DISPLAY_PREFIX_LENGTH,
  hashApiToken,
  isWellFormedToken,
} from "@/lib/auth/tokens";
import { logQueryError } from "@/lib/dashboard/api";
import { getDb, type DrizzleDb } from "@/lib/db/client";
import { apiTokens } from "@/lib/db/schema";
import { createServerSupabaseClient } from "@/lib/supabase/server";

/**
 * Second auth guard, used ONLY by routes under app/api/blog/** — a unit test
 * (lib/auth/blog-guard-scope.test.ts) enforces that, so a leaked blog token
 * can touch blog posts and blog media and nothing else. Token management
 * routes use requireAdminAuth: a token cannot mint or revoke tokens.
 *
 * A present-but-invalid Authorization header is a 401 and NEVER falls back to
 * the cookie session — otherwise a broken token would silently ride the
 * owner's session and misattribute agent writes as "admin".
 *
 * Deliberate omissions (spec → Authorization): no rate limiting (256-bit
 * tokens make online guessing infeasible; App Platform has no shared store)
 * and no token expiry (revocation + last_used_at cover the risk at T0).
 */

export type BlogActor =
  | { kind: "admin"; userId: string }
  | { kind: "agent"; tokenId: string };

type BlogAuthResult =
  | { actor: BlogActor; db: DrizzleDb; error?: undefined }
  | { error: NextResponse; actor?: undefined };

const LAST_USED_THROTTLE_MS = 60_000;

function unauthenticated(message: string): BlogAuthResult {
  return {
    error: NextResponse.json({ error: "UNAUTHENTICATED", message }, { status: 401 }),
  };
}

export async function requireBlogAuth(request: NextRequest): Promise<BlogAuthResult> {
  const header = request.headers.get("authorization");

  if (header !== null) {
    return authenticateToken(header);
  }

  return authenticateSession();
}

async function authenticateToken(header: string): Promise<BlogAuthResult> {
  const match = /^Bearer\s+(.+)$/i.exec(header);
  const token = match?.[1]?.trim() ?? "";

  if (!isWellFormedToken(token)) {
    return unauthenticated("Authorization header must carry a valid bearer token.");
  }

  const db = getDb();

  try {
    const rows = await db
      .select({
        id: apiTokens.id,
        last_used_at: apiTokens.last_used_at,
      })
      .from(apiTokens)
      .where(
        and(
          eq(apiTokens.token_hash, hashApiToken(token)),
          isNull(apiTokens.revoked_at),
          sql`'blog' = any(${apiTokens.scopes})`
        )
      )
      .limit(1);

    const row = rows[0];

    if (!row) {
      // Prefix only — the full value must never reach a log line.
      console.error(
        "Blog token rejected:",
        token.slice(0, TOKEN_DISPLAY_PREFIX_LENGTH)
      );
      return unauthenticated("Unknown, revoked, or out-of-scope token.");
    }

    const lastUsed = row.last_used_at ? new Date(row.last_used_at).getTime() : 0;

    if (Number.isNaN(lastUsed) || Date.now() - lastUsed >= LAST_USED_THROTTLE_MS) {
      try {
        await db
          .update(apiTokens)
          .set({ last_used_at: sql`timezone('utc'::text, now())` })
          .where(eq(apiTokens.id, row.id));
      } catch (error) {
        // Visibility metadata only — never fail the request over it.
        logQueryError("Token last_used_at update error:", error);
      }
    }

    return { actor: { kind: "agent", tokenId: row.id }, db };
  } catch (error) {
    logQueryError("Blog token lookup error:", error);
    return {
      error: NextResponse.json(
        { error: "INTERNAL_ERROR", message: "Internal server error." },
        { status: 500 }
      ),
    };
  }
}
```

```ts
const TOKEN_META_FIELDS = {

  name: apiTokens.name,

/**
 * GET /api/api-tokens — list token metadata, newest first.
 * Session-only (requireAdminAuth): a token cannot list tokens.
 */
export async function GET(request: NextRequest) {
  const authResult = await requireAdminAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { db } = authResult;

  try {
    const tokens = (await db
      .select(TOKEN_META_FIELDS)
      .from(apiTokens)
      .orderBy(desc(apiTokens.created_at))) as ApiTokenMeta[];

    return NextResponse.json({ tokens }, { status: 200 });
  } catch (error) {
    logQueryError("Token list error:", error);
    return apiError("SERVER_ERROR", "Could not load tokens.", 500);
  }
}

/**
 * POST /api/api-tokens — mint a blog-scoped token. The response is the ONLY
 * time the token value exists outside the caller's hands; it is never stored
 * or returned again.
 */
export async function POST(request: NextRequest) {
  const authResult = await requireAdminAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { db } = authResult;
  const body = await readJsonObject(request);

  if (!body) {
    return apiError("INVALID_BODY", "Request body must be a JSON object.", 400);
  }

  const name = typeof body.name === "string" ? body.name.trim() : "";

  if (!name || name.length > TOKEN_NAME_MAX_LENGTH) {
    return apiError(
      "INVALID_BODY",
      `name is required (≤ ${TOKEN_NAME_MAX_LENGTH} chars).`,
      400
    );
  }

  const minted = mintApiToken();

  try {
    const [row] = (await db
      .insert(apiTokens)
      .values({
        name,
        token_hash: minted.hash,
        token_prefix: minted.prefix,
        scopes: ["blog"],
      })
      .returning(TOKEN_META_FIELDS)) as ApiTokenMeta[];

    return NextResponse.json({ ...row, token: minted.token }, { status: 201 });
  } catch (error) {
    logQueryError("Token create error:", error);
    return apiError("SERVER_ERROR", "Could not create the token.", 500);
  }
```

```ts
import { and, eq, isNull, sql } from "drizzle-orm";
import { NextResponse, type NextRequest } from "next/server";

import { requireAdminAuth } from "@/lib/auth/admin-guard";
import { apiError, isUuid, logQueryError } from "@/lib/dashboard/api";
import { apiTokens } from "@/lib/db/schema";

/**
 * DELETE /api/api-tokens/[id] — soft revoke (sets revoked_at), so
 * blog_post_events rows keep a resolvable token reference. Session-only.
 * Revoking an already-revoked token is a 404: nothing changed.
 */
export async function DELETE(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  const authResult = await requireAdminAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { db } = authResult;
  const { id } = await params;

  if (!isUuid(id)) {
    return apiError("NOT_FOUND", "No token with that id.", 404);
  }

  try {
    const revoked = await db
      .update(apiTokens)
      .set({ revoked_at: sql`timezone('utc'::text, now())` })
      .where(and(eq(apiTokens.id, id), isNull(apiTokens.revoked_at)))
      .returning({ id: apiTokens.id });

    if (revoked.length === 0) {
      return apiError("NOT_FOUND", "No active token with that id.", 404);
    }

    return NextResponse.json({ ok: true }, { status: 200 });
  } catch (error) {
    logQueryError("Token revoke error:", error);
    return apiError("SERVER_ERROR", "Could not revoke the token.", 500);
  }
}
```

```ts
interface TagRule {
  /**
   * Serializes this tag's allowed attributes from the collected raw ones.
   * Returns the attribute string to emit (may be ""), or null to drop the
   * ELEMENT entirely. null is only legal for void tags (img) — a non-void
   * rule must never return it, because there is no skip-to-close pass.
   */
  attributes?: (attrs: ReadonlyMap<string, string>) => string | null;
}

interface SanitizeProfile {
  tags: ReadonlyMap<string, TagRule>;
}

/**
 * Minimal named-entity map for attribute-value decoding. Anything not listed
 * stays literal — and because emitted attribute values re-escape every "&",
 * an undecoded entity is inert in the output (the browser sees "&amp;colon;",
 * not ":"). Numeric references are decoded in full.
 */
const NAMED_ENTITIES: Record<string, string> = {
  amp: "&",
  lt: "<",
  gt: ">",
  quot: '"',
  apos: "'",
  nbsp: " ",
};

function codePointOrFallback(cp: number, fallback: string): string {
  if (cp === 0 || cp > 0x10ffff || (cp >= 0xd800 && cp <= 0xdfff)) {
    return fallback;
  }

  return String.fromCodePoint(cp);
}

/**
 * Decodes character references the way a browser would before IT reads an
 * attribute value — the step that defeats entity-obfuscated schemes like
 * `&#106;avascript:`. Validation always runs on the DECODED value.
 */
function decodeEntities(value: string): string {
  return value.replace(
    /&(?:#(\d{1,7})|#[xX]([0-9a-fA-F]{1,6})|([a-zA-Z][a-zA-Z0-9]{1,31}));/g,
    (whole, dec: string | undefined, hex: string | undefined, named: string | undefined) => {
      if (dec !== undefined) return codePointOrFallback(parseInt(dec, 10), whole);
      if (hex !== undefined) return codePointOrFallback(parseInt(hex, 16), whole);
      return NAMED_ENTITIES[named as string] ?? whole;
    }
  );
}

/** Escapes a DECODED attribute value for double-quoted emission. */
function escapeAttr(value: string): string {
  return value.replace(/[&<>"]/g, (ch) =>
    ch === "&" ? "&amp;" : ch === "<" ? "&lt;" : ch === ">" ? "&gt;" : "&quot;"
  );
}
```

```ts
/**
 * Finds where a tag ends, starting just past its name, collecting attributes
 * on the way. Same quote-tracking state machine as before — the piece a naive
 * /<[^>]*>/ gets wrong — now also recording name/value pairs so profiles can
 * allowlist attributes. Unterminated tags consume to end-of-input, unchanged.

function scanTag(html: string, from: number): ScannedTag {
  const attrs = new Map<string, string>();
  let state: TagScanState = "beforeAttr";
  let quote = "";
  let nameStart = -1;
  let name = "";
  let valueStart = -1;
  let i = from;

  function commit(value: string) {
    if (name && !attrs.has(name)) {
      attrs.set(name, decodeEntities(value));
    }

    name = "";
  }

  while (i < html.length) {
    const ch = html[i];

    switch (state) {
      case "beforeAttr":
        if (ch === ">") return { end: i + 1, attrs };
        if (WHITESPACE_PATTERN.test(ch) || ch === "/") {
          i += 1;
          break;
        }
        nameStart = i;
        state = "attrName";
        break;

      case "attrName":
        if (ch === ">") {
          name = html.slice(nameStart, i).toLowerCase();
          commit("");
          return { end: i + 1, attrs };
        }
        if (ch === "=") {
          name = html.slice(nameStart, i).toLowerCase();
          state = "beforeValue";
          i += 1;
          break;
        }
        if (WHITESPACE_PATTERN.test(ch)) {
          name = html.slice(nameStart, i).toLowerCase();
          state = "afterAttrName";
          i += 1;
          break;
        }
        i += 1;
        break;

      case "afterAttrName":
        if (ch === ">") {
          commit("");
          return { end: i + 1, attrs };
        }
        if (WHITESPACE_PATTERN.test(ch)) {
          i += 1;
          break;
        }
        if (ch === "=") {
          state = "beforeValue";
          i += 1;
          break;
        }
        commit("");
        nameStart = i;
        state = "attrName";
        break;

      case "beforeValue":
        if (ch === ">") {
          commit("");
          return { end: i + 1, attrs };
        }
        if (WHITESPACE_PATTERN.test(ch)) {
          i += 1;
          break;
        }
        if (ch === '"' || ch === "'") {
          quote = ch;
          valueStart = i + 1;
          state = "quotedValue";
          i += 1;
          break;
        }
        valueStart = i;
        state = "unquotedValue";
        break;

      case "quotedValue":
        if (ch === quote) {
          commit(html.slice(valueStart, i));
          state = "beforeAttr";
        }
        i += 1;
        break;

      case "unquotedValue":
        if (ch === ">") {
          commit(html.slice(valueStart, i));
          return { end: i + 1, attrs };
        }
        if (WHITESPACE_PATTERN.test(ch)) {
          commit(html.slice(valueStart, i));
          state = "beforeAttr";
          i += 1;
          break;
        }
        i += 1;
        break;
    }
  }

  // Unterminated tag: consumed and dropped, as before. In-flight attr discarded.
  return { end: html.length, attrs };
}

function scanTagEnd(html: string, from: number): number {
  return scanTag(html, from).end;
}
```

```ts
 * open-redirect lesson in AGENTS.md): a root-relative candidate is resolved

function sanitizeHref(raw: string): { value: string; external: boolean } | null {
  const value = raw.trim();

  if (!value) return null;

  if (/^(https?|mailto):/i.test(value)) {
    let parsed: URL;

    try {
      parsed = new URL(value);
    } catch {
      return null;
    }

    if (!["http:", "https:", "mailto:"].includes(parsed.protocol)) return null;
    if (parsed.protocol !== "mailto:" && !parsed.hostname) return null;
```

```ts
import type { DerivedStatus } from "@/lib/blog/types";
import { noteHtmlToText } from "@/lib/sanitize";

/** Caps checked against RAW request values, before sanitising. */
export const POST_TITLE_MAX_LENGTH = 200;
export const POST_EXCERPT_MAX_LENGTH = 300;
export const POST_SLUG_MAX_LENGTH = 100;
export const POST_MAX_TAGS = 8;

const READING_WPM = 225;
const SLUG_PATTERN = /^[a-z0-9]+(?:-[a-z0-9]+)*$/;
const TAG_PATTERN = /^[a-z0-9-]{1,32}$/;

export function isValidSlug(value: string): boolean {
  return value.length <= POST_SLUG_MAX_LENGTH && SLUG_PATTERN.test(value);
}

/**
 * Best-effort slug from a title. May legitimately return "" (all-symbol
 * title), which the caller turns into INVALID_SLUG asking for an explicit one.
 */
export function slugFromTitle(title: string): string {
  return title
    .normalize("NFKD")
    .replace(/[̀-ͯ]/g, "")
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "")
    .slice(0, POST_SLUG_MAX_LENGTH)
    .replace(/-+$/, "");
}

/**
 * Normalises a tags payload: trim, lowercase, inner whitespace → hyphen,
 * dedupe, order preserved. Null (⇒ INVALID_TAGS) when the payload is not an
 * array of valid tags or exceeds the cap — one bad tag fails the request, so
 * an agent's typo is surfaced instead of silently dropped.
 */
export function normalizeTags(raw: unknown): string[] | null {
  if (!Array.isArray(raw)) return null;

  const tags: string[] = [];

  for (const value of raw) {
    if (typeof value !== "string") return null;

    const tag = value.trim().toLowerCase().replace(/\s+/g, "-").replace(/-+/g, "-");

    if (!TAG_PATTERN.test(tag)) return null;
    if (!tags.includes(tag)) tags.push(tag);
  }

  return tags.length <= POST_MAX_TAGS ? tags : null;
}

/** ≈225 wpm over the text rendering of the sanitised body, floor 1. */
export function readingMinutes(contentHtml: string): number {
  const words = noteHtmlToText(contentHtml).split(/\s+/).filter(Boolean).length;

  return Math.max(1, Math.ceil(words / READING_WPM));
}

/**
 * "Live" is the derived state the whole feature pivots on: published AND
 * published_at in the past. A published post with a future date is Scheduled
 * — same row, no cron, it becomes live by time passing (spec → data model).
 */
export function isLive(
  post: { status: string; published_at: string | null },
  now: Date = new Date()
): boolean {
  if (post.status !== "published" || post.published_at === null) return false;

  const at = new Date(post.published_at).getTime();

  return !Number.isNaN(at) && at <= now.getTime();
}

export function deriveStatus(
  post: { status: string; published_at: string | null },
  now: Date = new Date()
): DerivedStatus {
  if (post.status !== "published") return "draft";

  return isLive(post, now) ? "published" : "scheduled";
}

/** Normalises a published_at input to ISO; null when unusable (⇒ INVALID_DATE). */
export function parsePublishedAtInput(raw: unknown): string | null {
  if (typeof raw !== "string" || !raw.trim()) return null;

  const date = new Date(raw);

  return Number.isNaN(date.getTime()) ? null : date.toISOString();
}
```

```ts
/**
 * GET /api/blog/posts — all posts, updated_at desc. `?status=` filters are
 * DERIVED: published = live (published_at <= now), scheduled = published with
 * a future date; there is no 'scheduled' column value.

export async function GET(request: NextRequest) {

  if (authResult.error) {
    return authResult.error;
  }

  const { db } = authResult;
  const statusParam = request.nextUrl.searchParams.get("status");

  if (statusParam !== null && !["draft", "published", "scheduled"].includes(statusParam)) {
    return apiError("INVALID_BODY", "status must be draft, published, or scheduled.", 400);
  }

  const filter =
    statusParam === "draft"
      ? eq(blogPosts.status, "draft")
      : statusParam === "published"
        ? and(eq(blogPosts.status, "published"), sql`${blogPosts.published_at} <= now()`)
        : statusParam === "scheduled"
          ? and(eq(blogPosts.status, "published"), sql`${blogPosts.published_at} > now()`)
          : undefined;

  try {
    const posts = (await db
      .select(LIST_FIELDS)
      .from(blogPosts)
      .where(filter)
      .orderBy(desc(blogPosts.updated_at))) as BlogPostListItem[];

    return NextResponse.json({ posts }, { status: 200 });
  } catch (error) {
    logQueryError("Post list error:", error);
    return apiError("SERVER_ERROR", "Could not load posts.", 500);
  }
}

/**
 * POST /api/blog/posts — create. Validation order: cheap shape checks, then
 * slug, tags, date, publish rules; content is sanitised server-side (the
 * client is never the only sanitiser). 23505 on slug → SLUG_TAKEN 409.
 */
export async function POST(request: NextRequest) {
  const authResult = await requireBlogAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { actor, db } = authResult;
  const body = await readJsonObject(request);

  if (!body) {
    return apiError("INVALID_BODY", "Request body must be a JSON object.", 400);
  }

  const title = typeof body.title === "string" ? body.title.trim() : "";

  if (!title) {
    return apiError("INVALID_BODY", "title is required.", 400);
  }

  if (title.length > POST_TITLE_MAX_LENGTH) {
    return apiError("INVALID_TITLE", `title must be ≤ ${POST_TITLE_MAX_LENGTH} chars.`, 400);
  }

  let slug: string;

  if (body.slug !== undefined) {
    if (typeof body.slug !== "string" || !isValidSlug(body.slug)) {
      return apiError(
        "INVALID_SLUG",
        "slug must be lowercase letters/digits with single hyphens, ≤ 100 chars.",
        400
      );
    }

    slug = body.slug;
  } else {
    slug = slugFromTitle(title);

    if (!slug) {
      return apiError(
        "INVALID_SLUG",
        "The title yields no usable slug — provide one explicitly.",
        400
      );
    }
  }

  const excerpt = typeof body.excerpt === "string" ? body.excerpt.trim() : "";

  if (excerpt.length > POST_EXCERPT_MAX_LENGTH) {
    return apiError("INVALID_BODY", `excerpt must be ≤ ${POST_EXCERPT_MAX_LENGTH} chars.`, 400);
  }

  const rawContent = typeof body.content_html === "string" ? body.content_html : "";

  if (rawContent.length > POST_CONTENT_MAX_LENGTH) {
    return apiError("INVALID_CONTENT", "content_html is too large.", 400);
  }

  const tags = body.tags === undefined ? [] : normalizeTags(body.tags);

  if (tags === null) {
    return apiError(
      "INVALID_TAGS",
      "tags must be ≤ 8 strings of lowercase letters, digits, hyphens (≤ 32 chars each).",
      400
    );
  }

  const status: PostStatus = body.status === "published" ? "published" : "draft";

  if (body.status !== undefined && body.status !== "draft" && body.status !== "published") {
    return apiError("INVALID_BODY", "status must be 'draft' or 'published'.", 400);
  }

  let publishedAt: string | null = null;

  if (body.published_at !== undefined && body.published_at !== null) {
    publishedAt = parsePublishedAtInput(body.published_at);

    if (publishedAt === null) {
      return apiError("INVALID_DATE", "published_at must be an ISO 8601 datetime.", 400);
    }
  }

  if (status === "published") {
    if (!excerpt) {
      return apiError("EXCERPT_REQUIRED", "A non-empty excerpt is required to publish.", 400);
    }

    publishedAt = publishedAt ?? new Date().toISOString();
  }

  const contentHtml = sanitizePostHtml(rawContent, { mediaOrigin: getSpacesMediaCdnUrl() });
  const actorKind = actor.kind === "admin" ? ("admin" as const) : ("agent" as const);
  const tokenId = actor.kind === "agent" ? actor.tokenId : null;

  try {
    const post = await db.transaction(async (tx) => {
      const [created] = (await tx
        .insert(blogPosts)
        .values({
          slug,
          title,
          excerpt,
          content_html: contentHtml,
          status,
          published_at: publishedAt,
          tags,
          reading_minutes: readingMinutes(contentHtml),
          created_by: actorKind,
          updated_by: actorKind,
          created_by_token_id: tokenId,
          updated_by_token_id: tokenId,
        })
        .returning()) as BlogPost[];

      await recordPostEvent(tx, {
        postId: created.id,
        postTitle: created.title,
        actor: actorKind,
        tokenId,
        action: "created",
      });

      if (created.status === "published") {
        await recordPostEvent(tx, {
          postId: created.id,
          postTitle: created.title,
          actor: actorKind,
          tokenId,
          action: "published",
          summary: isLive(created) ? "" : "scheduled",
        });
      }

      return created;
    });

    revalidateBlog();

    return NextResponse.json(post, { status: 201 });
  } catch (error) {
    if (postgresErrorCode(error) === UNIQUE_VIOLATION) {
      return apiError("SLUG_TAKEN", "A post with that slug already exists.", 409);
    }

    logQueryError("Post create error:", error);
    return apiError("SERVER_ERROR", "Could not create the post.", 500);
  }
}
```

```ts
/**
 * PATCH /api/blog/posts/[id] — partial update, same validation as POST.
 *
 * Concurrency: an optional `if_updated_at` must equal the stored updated_at
 * EXACTLY (string compare) or the request 409s — how an agent edit racing the
 * owner's open editor is surfaced instead of silently overwritten.
 *
 * Slug lock: a LIVE post's slug cannot change (SLUG_LOCKED 409) — unpublish
 * first, deliberately, because renames break inbound links.
 *
 * published_at preservation: publishing keeps an existing published_at unless
 * one is explicitly supplied, and defaults to now only when null; unpublishing
 * never nulls it. The slug lock pushes the owner toward
 * unpublish → edit → republish, and that cycle must not reset the post's date.
 */
export async function PATCH(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  const authResult = await requireBlogAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { actor, db } = authResult;
  const { id } = await params;

  if (!isUuid(id)) {
    return apiError("NOT_FOUND", "No post with that id.", 404);
  }

  const body = await readJsonObject(request);

  if (!body) {
    return apiError("INVALID_BODY", "Request body must be a JSON object.", 400);
  }

  let existing: BlogPost | undefined;

  try {
    existing = await loadPost(db, id);
  } catch (error) {
    logQueryError("Post read error:", error);
    return apiError("SERVER_ERROR", "Could not load the post.", 500);
  }

  if (!existing) {
    return apiError("NOT_FOUND", "No post with that id.", 404);
  }

  if ("if_updated_at" in body) {
    if (typeof body.if_updated_at !== "string") {
      return apiError("INVALID_BODY", "if_updated_at must be a string.", 400);
    }

    if (body.if_updated_at !== existing.updated_at) {
      return apiError(
        "CONFLICT",
        "This post changed since you loaded it — reload and retry.",
        409
      );
    }
  }

  const updates: PostUpdate = {};
  const changed: string[] = [];

  if ("title" in body) {
    if (typeof body.title !== "string" || !body.title.trim()) {
      return apiError("INVALID_BODY", "title must be a non-empty string.", 400);
    }

    if (body.title.trim().length > POST_TITLE_MAX_LENGTH) {
      return apiError("INVALID_TITLE", `title must be ≤ ${POST_TITLE_MAX_LENGTH} chars.`, 400);
    }

    updates.title = body.title.trim();

    if (updates.title !== existing.title) changed.push("title");
  }

  if ("slug" in body) {
    if (typeof body.slug !== "string" || !isValidSlug(body.slug)) {
      return apiError(
        "INVALID_SLUG",
        "slug must be lowercase letters/digits with single hyphens, ≤ 100 chars.",
        400
      );
    }

    if (body.slug !== existing.slug) {
      if (isLive(existing)) {
        return apiError(
          "SLUG_LOCKED",
          "A live post's slug cannot change — unpublish first.",
          409
        );
      }

      updates.slug = body.slug;
      changed.push("slug");
    }
  }

  if ("excerpt" in body) {
    if (typeof body.excerpt !== "string") {
      return apiError("INVALID_BODY", "excerpt must be a string.", 400);
    }

    const excerpt = body.excerpt.trim();

    if (excerpt.length > POST_EXCERPT_MAX_LENGTH) {
      return apiError("INVALID_BODY", `excerpt must be ≤ ${POST_EXCERPT_MAX_LENGTH} chars.`, 400);
    }

    updates.excerpt = excerpt;

    if (excerpt !== existing.excerpt) changed.push("excerpt");
  }

  if ("content_html" in body) {
    if (typeof body.content_html !== "string") {
      return apiError("INVALID_BODY", "content_html must be a string.", 400);
    }

    if (body.content_html.length > POST_CONTENT_MAX_LENGTH) {
      return apiError("INVALID_CONTENT", "content_html is too large.", 400);
    }

    const contentHtml = sanitizePostHtml(body.content_html, {
      mediaOrigin: getSpacesMediaCdnUrl(),
    });

    updates.content_html = contentHtml;
    updates.reading_minutes = readingMinutes(contentHtml);

    if (contentHtml !== existing.content_html) changed.push("content");
  }

  if ("tags" in body) {
    const tags = normalizeTags(body.tags);

    if (tags === null) {
      return apiError(
        "INVALID_TAGS",
        "tags must be ≤ 8 strings of lowercase letters, digits, hyphens (≤ 32 chars each).",
        400
      );
    }

    updates.tags = tags;

    if (JSON.stringify(tags) !== JSON.stringify(existing.tags)) changed.push("tags");
  }

  if ("published_at" in body && body.published_at !== null) {
    const publishedAt = parsePublishedAtInput(body.published_at);

    if (publishedAt === null) {
      return apiError("INVALID_DATE", "published_at must be an ISO 8601 datetime.", 400);
    }

    updates.published_at = publishedAt;

    if (publishedAt !== existing.published_at) changed.push("published_at");
  }

  let action: PostAction = "updated";

  if ("status" in body) {
    if (body.status !== "draft" && body.status !== "published") {
      return apiError("INVALID_BODY", "status must be 'draft' or 'published'.", 400);
    }

    if (body.status !== existing.status) {
      updates.status = body.status;
      changed.push("status");

      if (body.status === "published") {
        const effectiveExcerpt = updates.excerpt ?? existing.excerpt;

        if (!effectiveExcerpt) {
          return apiError(
            "EXCERPT_REQUIRED",
            "A non-empty excerpt is required to publish.",
            400
          );
        }

        // Preservation rule: explicit value > existing value > now.
        updates.published_at =
          updates.published_at ?? existing.published_at ?? new Date().toISOString();
        action = "published";
      } else {
        // Unpublish keeps published_at — never nulled.
        action = "unpublished";
      }
    }
  }

  if (Object.keys(updates).length === 0) {
    return apiError("INVALID_BODY", "No updatable fields were provided.", 400);
  }

  const actorKind = actor.kind === "admin" ? ("admin" as const) : ("agent" as const);

  updates.updated_by = actorKind;
  updates.updated_by_token_id = actor.kind === "agent" ? actor.tokenId : null;

  try {
    const post = await db.transaction(async (tx) => {
      const [saved] = (await tx
        .update(blogPosts)
        .set(updates)
        .where(eq(blogPosts.id, id))
        .returning()) as BlogPost[];

      // A PATCH that changed nothing observable (e.g. autosave resending the
      // same text) bumps updated_at but earns no log row — the activity log
      // records changes, not keystrokes.
      if (action !== "updated" || changed.length > 0) {
        await recordPostEvent(tx, {
          postId: saved.id,
          postTitle: saved.title,
          actor: actorKind,
          tokenId: actor.kind === "agent" ? actor.tokenId : null,
          action,
          summary: changed.join(", "),
        });
      }

      return saved;
    });

    revalidateBlog();

    return NextResponse.json(post, { status: 200 });
  } catch (error) {
    if (postgresErrorCode(error) === UNIQUE_VIOLATION) {
      return apiError("SLUG_TAKEN", "A post with that slug already exists.", 409);
    }

    logQueryError("Post update error:", error);
    return apiError("SERVER_ERROR", "Could not update the post.", 500);
  }
}

/**
 * DELETE /api/blog/posts/[id] — hard delete. The 'deleted' event is written
 * BEFORE the row goes (same transaction); the FK's on-delete-set-null then
 * detaches it, so history survives with the title snapshot.
 */
export async function DELETE(
  request: NextRequest,
  { params }: { params: Promise<{ id: string }> }
) {
  const authResult = await requireBlogAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const { actor, db } = authResult;
  const { id } = await params;

  if (!isUuid(id)) {
    return apiError("NOT_FOUND", "No post with that id.", 404);
  }

  const actorKind = actor.kind === "admin" ? ("admin" as const) : ("agent" as const);

  try {
    const existing = await loadPost(db, id);

    if (!existing) {
      return apiError("NOT_FOUND", "No post with that id.", 404);
    }

    await db.transaction(async (tx) => {
      await recordPostEvent(tx, {
        postId: existing.id,
        postTitle: existing.title,
        actor: actorKind,
        tokenId: actor.kind === "agent" ? actor.tokenId : null,
        action: "deleted",
      });

      await tx.delete(blogPosts).where(eq(blogPosts.id, id));
    });

    revalidateBlog();

    return NextResponse.json({ ok: true }, { status: 200 });
  } catch (error) {
    logQueryError("Post delete error:", error);
    return apiError("SERVER_ERROR", "Could not delete the post.", 500);
  }
}
```

```tsx
      showToast(error instanceof Error ? error.message : "Could not create the post.");
    } finally {
      setCreating(false);

    if (!activePost || busy) return;

    flushPending();
    setBusy(true);

    const base = baselineRef.current.get(activePost.id);

    try {
      const response = await fetch(`/api/blog/posts/${activePost.id}`, {
        method: "PATCH",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ ...patch, if_updated_at: base?.updated_at }),
      });

      if (response.status === 409) {
        throw new Error(await readApiError(response, "This post changed — reload."));
      }

      if (!response.ok) {
        throw new Error(await readApiError(response, "Could not save the post."));
      }

      const saved: BlogPost = await response.json();

      applySaved(saved, false);
      loadedPostIdRef.current = null; // reload editor markup from the server copy
      setSaveState("saved");

      return saved;
    } catch (error) {
      showToast(error instanceof Error ? error.message : "Could not save the post.");
      return undefined;
    } finally {
      setBusy(false);
    }
  }

  function diffPatch(): PostPatch {
    if (!activePost) return {};

    const base = baselineRef.current.get(activePost.id);
    const patch: PostPatch = {};

    if (!base) return patch;
    if (activePost.title !== base.title) patch.title = activePost.title;
    if (activePost.content_html !== base.content_html) patch.content_html = activePost.content_html;
    if (activePost.excerpt !== base.excerpt) patch.excerpt = activePost.excerpt;
    if (activePost.slug !== base.slug) patch.slug = activePost.slug;
    if (activePost.published_at !== base.published_at && activePost.published_at)
      patch.published_at = activePost.published_at;
    if (JSON.stringify(activePost.tags) !== JSON.stringify(base.tags)) patch.tags = activePost.tags;

    return patch;
  }

    if (!activePost) return;

    if (!activePost.excerpt.trim()) {
      showToast("Add an excerpt before publishing.");
      return;
    }

    const saved = await sendExplicit({
      ...diffPatch(),
      status: "published",
      ...(activePost.published_at ? { published_at: activePost.published_at } : {}),
    });

    if (saved) showToast(deriveStatus(saved) === "scheduled" ? "Post scheduled" : "Post published");
  }

  }

  async function handleUnpublish() {
    const saved = await sendExplicit({ status: "draft" });

    if (saved) showToast("Post unpublished");
  }

  async function handleDelete() {
    if (!activePost) return;

    const target = activePost;

    setMenuOpen(false);
    setConfirmingDelete(false);

      pendingRef.current = null;

        timerRef.current = null;
      }
    }

      if (!response.ok) {
        throw new Error(await readApiError(response, "Could not delete the post."));
      }

      showToast("Post deleted");
    } catch (error) {
      setPosts((previous) =>
        previous.some((post) => post.id === target.id) ? previous : [...previous, target]
      );
      showToast(error instanceof Error ? error.message : "Could not delete the post.");
    }
  }
```

```ts
import { noteHtmlToText } from "@/lib/sanitize";

/**
 * THE public read: every live post, newest first, full rows (the index, slug
 * pages, RSS and sitemap all carve from this one cache entry). Cached under
 * the "blog" tag with a 300s revalidate — the only two invalidation paths are
 * time (how scheduled posts go live with no cron) and revalidateBlog() on
 * mutation. Pages calling this must be dynamic (`force-dynamic`): the classic
 * static model would run this query at BUILD time, where DATABASE_URL does
 * not exist on App Platform (RUN_TIME-scoped — see docs/ARCHITECTURE.md).
 */
const readLivePosts = unstable_cache(
  async (): Promise<BlogPost[]> => {
    const db = getDb();

    return (await db
      .select()
      .from(blogPosts)
      .where(
        and(eq(blogPosts.status, "published"), sql`${blogPosts.published_at} <= now()`)
      )
      .orderBy(desc(blogPosts.published_at))) as BlogPost[];
  },
  ["blog-live-posts"],
  { tags: [BLOG_CACHE_TAG], revalidate: 300 }
);

export function getLivePosts(): Promise<BlogPost[]> {
  return readLivePosts();
}

export async function getLivePost(slug: string): Promise<BlogPost | null> {
  return (await readLivePosts()).find((post) => post.slug === slug) ?? null;
}

export async function getPostNeighbors(
  slug: string
): Promise<{ newer: BlogPost | null; older: BlogPost | null }> {
  const posts = await readLivePosts();
  const index = posts.findIndex((post) => post.slug === slug);

  if (index === -1) {
    return { newer: null, older: null };
  }

  // posts is newest-first.
  return { newer: posts[index - 1] ?? null, older: posts[index + 1] ?? null };
}

/**
 * Anchor ids for h2/h3, added at RENDER time so the stored HTML stays
 * canonical (spec §HTML). The regex is safe HERE and only here: this runs on
 * sanitizePostHtml output, where headings are guaranteed attribute-free and
 * balanced — the conditions the sanitiser's own docs say a naive regex needs.
 */
export function addHeadingIds(html: string): string {
  const seen = new Map<string, number>();

  return html.replace(/<(h[23])>([\s\S]*?)<\/\1>/g, (whole, tag: string, inner: string) => {
    const base = slugFromTitle(noteHtmlToText(inner));

    if (!base) {
      return whole;
    }

    const count = (seen.get(base) ?? 0) + 1;

    seen.set(base, count);

    const id = count === 1 ? base : `${base}-${count}`;

    return `<${tag} id="${id}">${inner}</${tag}>`;
  });
}

/**
 * RSS carries full HTML, and a feed reader has no origin to resolve "/x"
 * against — root-relative hrefs must become absolute (spec §Public pages).
 * Sanitised output guarantees root-relative hrefs start with exactly one "/",
 * double-quoted, so the replace cannot touch absolute URLs.
 */
export function rewriteRelativeHrefs(html: string, origin: string): string {
  const base = origin.replace(/\/+$/, "");

  return html.replace(/href="\//g, `href="${base}/`);
}

export function escapeXml(value: string): string {
  return value
    .replace(/&/g, "&amp;")
    .replace(/</g, "&lt;")
    .replace(/>/g, "&gt;")
    .replace(/"/g, "&quot;")
    .replace(/'/g, "&apos;");
}
```

```ts
 * (Windows registers none for some extensions; see the MIME lesson in
 * AGENTS.md) and file names are attacker-chosen. No SVG, deliberately: it is
 * a script vector (spec §Media).
 */

export const MAX_IMAGE_BYTES = 10 * 1024 * 1024;

export interface SniffedImage {
  contentType: "image/jpeg" | "image/png" | "image/gif" | "image/webp";
  extension: "jpg" | "png" | "gif" | "webp";
}

export function sniffImage(buffer: Buffer): SniffedImage | null {
  if (buffer.length >= 3 && buffer[0] === 0xff && buffer[1] === 0xd8 && buffer[2] === 0xff) {
    return { contentType: "image/jpeg", extension: "jpg" };
  }

  if (
    buffer.length >= 8 &&
    buffer[0] === 0x89 &&
    buffer.subarray(1, 4).toString("ascii") === "PNG" &&
    buffer[4] === 0x0d &&
    buffer[5] === 0x0a &&
    buffer[6] === 0x1a &&
    buffer[7] === 0x0a
  ) {
    return { contentType: "image/png", extension: "png" };
  }

  const head6 = buffer.subarray(0, 6).toString("ascii");

  if (head6 === "GIF87a" || head6 === "GIF89a") {
    return { contentType: "image/gif", extension: "gif" };
  }

  if (
    buffer.length >= 12 &&
    buffer.subarray(0, 4).toString("ascii") === "RIFF" &&
    buffer.subarray(8, 12).toString("ascii") === "WEBP"
  ) {
    return { contentType: "image/webp", extension: "webp" };
  }

  return null;
}
```

```ts
import { PutObjectCommand, S3Client } from "@aws-sdk/client-s3";

import { getSpacesCredentials } from "@/lib/env";

/**
 * S3-compatible client for DigitalOcean Spaces. Bucket is a PARAMETER on
 * every call so migration Phase 2 can point this same module at a private
 * Documents bucket (spec §Media). deleteObject deliberately does not exist
 * yet — nothing in v1 deletes objects.
 */

let client: S3Client | null = null;

function getClient(): S3Client {
  if (!client) {
    const { key, secret, region } = getSpacesCredentials();

    client = new S3Client({
      // Spaces ignores the AWS region but the SDK requires one; the real
      // routing is the endpoint.
      region: "us-east-1",
      endpoint: `https://${region}.digitaloceanspaces.com`,
      credentials: { accessKeyId: key, secretAccessKey: secret },
    });
  }

  return client;
}

export async function putPublicObject(options: {
  bucket: string;
  key: string;
  body: Buffer;
  contentType: string;
}): Promise<void> {
  await getClient().send(
    new PutObjectCommand({
      Bucket: options.bucket,
      Key: options.key,
      Body: options.body,
      ContentType: options.contentType,
      ACL: "public-read",
      // Keys embed a UUID, so objects are immutable by construction.
      CacheControl: "public, max-age=31536000, immutable",
    })
  );
}

export function publicUrl(cdnUrl: string, key: string): string {
  return `${cdnUrl.replace(/\/+$/, "")}/${key}`;
}
```

```ts
import crypto from "crypto";
import { imageSize } from "image-size";
import { NextResponse, type NextRequest } from "next/server";

import { requireBlogAuth } from "@/lib/auth/blog-guard";
import { MAX_IMAGE_BYTES, sniffImage } from "@/lib/blog/images";
import { apiError, logQueryError } from "@/lib/dashboard/api";
import { getSpacesMediaBucket, getSpacesMediaCdnUrl } from "@/lib/env";
import { publicUrl, putPublicObject } from "@/lib/storage/spaces";

/**
 * POST /api/blog/media — multipart `file` (+ optional `alt`).
 * Images only in v1; the general name and response shape are deliberate so
 * future media types (videos → presigned uploads; see backlog) are additive.
 * Returns dimensions so <img width/height> can prevent layout shift.
 */
export async function POST(request: NextRequest) {
  const authResult = await requireBlogAuth(request);
  if (authResult.error) {
    return authResult.error;
  }

  const cdnUrl = getSpacesMediaCdnUrl();

  if (!cdnUrl) {
    return apiError("SERVER_ERROR", "Media storage is not configured.", 500);
  }

  try {
    const formData = await request.formData();
    const file = formData.get("file");
    const altRaw = formData.get("alt");

    if (!(file instanceof File)) {
      return apiError("INVALID_BODY", "No file was provided.", 400);
    }

    const buffer = Buffer.from(await file.arrayBuffer());

    if (buffer.byteLength > MAX_IMAGE_BYTES) {
      return apiError("IMAGE_TOO_LARGE", "Images must be 10 MB or smaller.", 400);
    }

    // Bytes decide the type — the browser-reported MIME is never consulted.
    const sniffed = sniffImage(buffer);

    if (!sniffed) {
      return apiError(
        "INVALID_IMAGE_TYPE",
        "Only JPEG, PNG, WebP, and GIF are accepted (sniffed, not by extension).",
        400
      );
    }

    let width: number | undefined;
    let height: number | undefined;

    try {
      const dims = imageSize(buffer);

      width = dims.width;
      height = dims.height;
    } catch {
      // Dimensions are a nicety; an undecodable-but-valid-magic file still uploads.
    }

    const now = new Date();
    const yyyy = String(now.getUTCFullYear());
    const mm = String(now.getUTCMonth() + 1).padStart(2, "0");
    const key = `blog/${yyyy}/${mm}/${crypto.randomUUID()}.${sniffed.extension}`;

    await putPublicObject({
      bucket: getSpacesMediaBucket(),
      key,
      body: buffer,
      contentType: sniffed.contentType,
    });

    return NextResponse.json(
      {
        url: publicUrl(cdnUrl, key),
        contentType: sniffed.contentType,
        width,
        height,
        alt: typeof altRaw === "string" && altRaw.trim() ? altRaw.trim() : null,
      },
      { status: 201 }
    );
  } catch (error) {
    logQueryError("Media upload error:", error);
    return apiError("STORAGE_ERROR", "Could not store the image.", 500);
  }
}
```

````markdown
# Blog API — agent contract

The API agents use to create, edit, publish, and delete blog posts on
patrickbeasley.com. Point an agent at this file; it needs nothing else.

**Base URL:** `https://www.patrickbeasley.com`
**Auth:** every request carries `Authorization: Bearer pbk_…` (a blog-scoped
token from Dashboard → Settings → Blog API tokens). Tokens are shown once at
creation and are revocable instantly. **Never put the token in post content,
logs, or URLs.** A missing header on a browser session also works (admin
cookie) — agents always use the header.

A present-but-invalid header is a 401; it never falls back to a session.
Tokens cannot manage tokens.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/blog/posts` | List all posts (no bodies). `?status=draft\|published\|scheduled` — `published` = live now, `scheduled` = future-dated. |
| POST | `/api/blog/posts` | Create. |
| GET | `/api/blog/posts/{id}` | Full post + last 20 activity events. |
| PATCH | `/api/blog/posts/{id}` | Partial update / publish / unpublish. |
| DELETE | `/api/blog/posts/{id}` | Hard delete (events survive). |
| GET | `/api/blog/posts/{id}/events` | Full activity log. |
| POST | `/api/blog/media` | Upload an image (multipart). |

Errors are `{ "error": "CODE", "message": "human text" }`. Codes you must
handle: `UNAUTHENTICATED` (401), `INVALID_SLUG`, `SLUG_TAKEN` (409),
`SLUG_LOCKED` (409 — live slug; unpublish first), `EXCERPT_REQUIRED`,
`INVALID_TAGS`, `INVALID_DATE`, `INVALID_TITLE`, `INVALID_CONTENT`,
`CONFLICT` (409 — stale `if_updated_at`; re-GET and retry),
`INVALID_IMAGE_TYPE`, `IMAGE_TOO_LARGE`, `NOT_FOUND`, `SERVER_ERROR`.

## Post fields

- `title` — required, ≤ 200 chars.
- `slug` — `^[a-z0-9]+(-[a-z0-9]+)*$`, ≤ 100 chars; generated from the title
  when omitted. A LIVE post's slug cannot change.
- `excerpt` — ≤ 300 chars; **required (non-empty) to publish**.
- `content_html` — HTML in the subset below, ≤ 200 000 chars.
- `tags` — ≤ 8 of `^[a-z0-9-]{1,32}$` (server lowercases/hyphenates).
- `status` — `draft` or `published`. Scheduled = `published` with a future
  `published_at`; the post goes live by itself within ~5 minutes of that time.
- `published_at` — ISO 8601. On publish: an explicit value wins; otherwise an
  existing value is KEPT; only a null one defaults to now. Unpublishing keeps it.
- Read-only: `reading_minutes`, `created_by`, `updated_by`, timestamps.

## Concurrency — send `if_updated_at`

Always include the post's current `updated_at` as `if_updated_at` in PATCH
bodies, copied verbatim from your last GET. A 409 `CONFLICT` means someone
(likely the owner's editor) changed the post — re-GET, merge, retry. Omitting
it silently overwrites their work; don't.

## HTML subset

Allowed: `p br strong b em i h2 h3 ul ol li blockquote pre code a img figure
figcaption hr`. **Anything else — tags or attributes — is silently removed**,
including whole `<img>` elements whose `src` is not on the blog CDN.

- `a href` — `https:`, `http:`, `mailto:`, or a root-relative path (`/…`).
- `img src` — must be a URL returned by `/api/blog/media`. `alt` (≤ 300
  chars), `width`, `height` (integers) are kept — always set width/height
  from the upload response to avoid layout shift.
- Heading anchors are generated at render time; do not add `id` attributes.

## Image upload flow

1. `POST /api/blog/media` with multipart field `file` (JPEG/PNG/WebP/GIF by
   magic bytes, ≤ 10 MB; SVG is rejected). Optional field `alt`.
2. Response: `201 { "url", "contentType", "width", "height", "alt" }`.
3. Reference it: `<img src="{url}" alt="…" width="{width}" height="{height}">`.
   Upload FIRST, then write the post.

## Recipes

Create a draft → `POST /api/blog/posts` `{ "title": "…", "content_html": "…", "excerpt": "…", "tags": ["…"] }`
Publish now → `PATCH …/{id}` `{ "status": "published", "if_updated_at": "…" }`
Schedule → `PATCH …/{id}` `{ "status": "published", "published_at": "2026-11-01T09:00:00Z", "if_updated_at": "…" }`
Unpublish → `PATCH …/{id}` `{ "status": "draft", "if_updated_at": "…" }`
Rename a live post's slug → unpublish, PATCH the slug, republish (the original
`published_at` is preserved automatically).
````
